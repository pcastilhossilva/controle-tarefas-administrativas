# Sistema de Controle de Tarefas Administrativas

## 📋 Objetivo do projeto

Este projeto tem como objetivo desenvolver uma aplicação simples para 
organizar e controlar tarefas administrativas do dia a dia (como 
conferência de contratos, prazos e documentos), automatizando um processo 
que hoje é feito manualmente em planilhas.

A ideia surgiu da minha experiência prática em rotinas administrativas, 
onde identifiquei a necessidade de um controle mais organizado e visual 
das tarefas e seus prazos.

## 🛠️ Tecnologias utilizadas

- **Python** — lógica principal da aplicação
- **SQL / Banco de Dados** — armazenamento das tarefas, status e prazos
- **Git e GitHub** — versionamento e documentação do projeto

## ⚙️ Funcionalidades

- Cadastro de tarefas com título, prazo e responsável
- Atualização de status (pendente, em andamento, concluída)
- Consulta de tarefas por prazo ou status
- Armazenamento persistente em banco de dados

## 📚 O que foi aprendido

Durante o desenvolvimento deste projeto, aprofundei meus conhecimentos em:

- Lógica de programação aplicada a um problema real
- Modelagem básica de banco de dados (estrutura de tabelas e relações)
- Organização de código e documentação técnica
- Uso do Git para versionar e documentar o progresso do projeto

Esse projeto também reforçou como conhecimentos técnicos podem resolver 
problemas que eu já enfrentava na prática, na rotina administrativa, 
tornando processos mais rápidos e confiáveis.
